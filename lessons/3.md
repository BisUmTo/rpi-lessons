# Esercitazione 3A: Semaforo via HTTP

In questa esercitazione utilizzeremo il framework Python "Flask" per creare un web server locale sul Raspberry Pi. Questo server risponderà a specifiche richieste HTTP (GET) per accendere o spegnere i LED di un modulo semaforo.

## 1. Connessione al Raspberry Pi

Grazie alla configurazione effettuata nella Lezione 2, il tuo Raspberry Pi ora genera una propria rete Wi-Fi.

1. Connettiti dal tuo PC alla rete Wi-Fi che hai creato.  
2. Apri il terminale (o CMD) ed effettua l'accesso SSH. Siccome abbiamo impostato un indirizzo statico, il comando sarà uguale per tutti i gruppi:  
   ```bash
   ssh pi@192.168.83.1
   ```
3. Inserisci la tua password (di default `raspberry`).

## 2. Preparazione

**Hardware necessario:**

* 1x Modulo minisemaforo (3 LED con resistenze integrate 330Ω)  
* Cavetti Dupont femmina-femmina

Fai riferimento a questa immagine per la piedinatura del Raspberry Pi:
![Piedinatura Raspberry Pi](https://i.sstatic.net/RILry.png)

## 3. Collegamenti

**Collegamenti (Pinout BCM):**

* **GND** del semaforo ➔ **Pin Fisico 6** (GND)  
* **R (Rosso)** ➔ **Pin Fisico 11** (GPIO 17)  
* **Y (Giallo)** ➔ **Pin Fisico 13** (GPIO 27)  
* **G (Verde)** ➔ **Pin Fisico 15** (GPIO 22)

## 4. Installazione di Flask

Assicurati che i pacchetti siano aggiornati e installa Flask, la libreria che ci permetterà di creare il sito web:

```bash
sudo apt update  
sudo apt install python3-flask -y
```

## 5. Creazione del Server Web

Crea un nuovo file Python chiamato `semaforo.py`:

```bash
nano semaforo.py
```

Riportare al suo interno il seguente codice:

```python
from flask import Flask  
import RPi.GPIO as GPIO

app = Flask(__name__)

# Definizione dei pin BCM  
PIN_ROSSO = 17  
PIN_GIALLO = 27  
PIN_VERDE = 22

# Configurazione GPIO  
GPIO.setmode(GPIO.BCM)  
GPIO.setwarnings(False)  
GPIO.setup(PIN_ROSSO, GPIO.OUT)  
GPIO.setup(PIN_GIALLO, GPIO.OUT)  
GPIO.setup(PIN_VERDE, GPIO.OUT)

# Funzione di supporto per spegnere tutto  
def spegni_tutti():  
    GPIO.output(PIN_ROSSO, GPIO.LOW)  
    GPIO.output(PIN_GIALLO, GPIO.LOW)  
    GPIO.output(PIN_VERDE, GPIO.LOW)

# Route per il Rosso  
@app.route('/rosso')  
def rosso():  
    spegni_tutti()  
    GPIO.output(PIN_ROSSO, GPIO.HIGH)  
    return "<h1>Semaforo: ROSSO</h1>"

# Route per il Giallo  
@app.route('/giallo')  
def giallo():  
    spegni_tutti()  
    GPIO.output(PIN_GIALLO, GPIO.HIGH)  
    return "<h1>Semaforo: GIALLO</h1>"

# Route per il Verde  
@app.route('/verde')  
def verde():  
    spegni_tutti()  
    GPIO.output(PIN_VERDE, GPIO.HIGH)  
    return "<h1>Semaforo: VERDE</h1>"

if __name__ == '__main__':  
    # Spegniamo i LED all'avvio  
    spegni_tutti()  
    # Avviamo il server sulla porta 5000, accessibile da tutta la rete locale  
    app.run(host='0.0.0.0', port=5000)
```

Salva ed esci (`Ctrl+X`, poi `Y` e `Invio`).

## 6. Esecuzione e Test

Avvia il tuo script Python:

```bash
python3 semaforo.py
```

Ora, apri il browser sul tuo PC o smartphone (connesso alla rete del Raspberry) e digita:

* http://192.168.83.1:5000/rosso  
* http://192.168.83.1:5000/giallo  
* http://192.168.83.1:5000/verde

Vedrai il semaforo reagire di conseguenza e accendere il LED corrispondente. Per fermare il server, premi `Ctrl+C` nel terminale SSH.
