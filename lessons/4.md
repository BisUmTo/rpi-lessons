# Esercitazione 3B: Buzzer di Errore via HTTP

In questa esercitazione utilizzeremo il framework Python "Flask" per creare un web server locale sul Raspberry Pi. Questo server risponderà a specifiche richieste HTTP (GET) per emettere segnali acustici di diversa durata e frequenza tramite un buzzer passivo.

## 1. Connessione al Raspberry Pi

Grazie alla configurazione effettuata nella Lezione 2, il tuo Raspberry Pi ora genera una propria rete Wi-Fi.

1. Connettiti dal tuo PC alla rete Wi-Fi che hai creato.  
2. Apri il terminale (o CMD) ed effettua l'accesso SSH. Siccome abbiamo impostato un indirizzo statico, il comando sarà uguale per tutti i gruppi:  
   ```bash
   ssh pi@192.168.83.1
   ```
3. Inserisci la tua password (di default `raspberry`).

## 2. Installazione di Flask

Se non l'hai già fatto in un'esercitazione precedente, aggiorna i pacchetti e installa Flask, la libreria che ci permetterà di creare il sito web:

```bash
sudo apt update  
sudo apt install python3-flask -y
```

## 3. Preparazione e Collegamenti

**Hardware necessario:**

## 4. Collegamenti

**Attenzione ai pin del modulo HW-508:** Guardando il modulo frontalmente (con i pin rivolti verso il basso):

* **Pin a Sinistra:** GND (Massa)  
* **Pin in Mezzo:** VCC (3.3V)  
* **Pin a Destra:** S / Segnale (I/O)

**Collegamenti (Pinout BCM):**

* **GND (Sinistra)** del buzzer ➔ **Pin Fisico 14** (GND)  
* **VCC (Mezzo)** del buzzer ➔ **Pin Fisico 1** (3.3V)  
* **Segnale (Destra)** ➔ **Pin Fisico 12** (GPIO 18 - Supporta il PWM Hardware)

## 5. Creazione del Server Web

Crea un nuovo file Python chiamato `buzzer_web.py`:

```bash
nano buzzer_web.py
```

Riportare al suo interno il seguente codice:

```python
from flask import Flask  
import RPi.GPIO as GPIO  
import time

app = Flask(__name__)

BUZZER_PIN = 18

# Configurazione GPIO  
GPIO.setmode(GPIO.BCM)  
GPIO.setwarnings(False)  
GPIO.setup(BUZZER_PIN, GPIO.OUT)

# Inizializzazione PWM (frequenza di default 440Hz)  
pwm = GPIO.PWM(BUZZER_PIN, 440)

# Route per il suono Lungo (2 secondi)  
@app.route('/lungo')  
def lungo():  
    pwm.start(50) # Duty cycle al 50%  
    pwm.ChangeFrequency(800)  
    time.sleep(2)  
    pwm.stop()  
    return "<h1>Buzzer: ERRORE LUNGO (2 secondi)</h1>"

# Route per il suono Corto (0.5 secondi)  
@app.route('/corto')  
def corto():  
    pwm.start(50)  
    pwm.ChangeFrequency(800)  
    time.sleep(0.5)  
    pwm.stop()  
    return "<h1>Buzzer: ERRORE CORTO (0.5 secondi)</h1>"

# Route per la Sirena (2 secondi, frequenze alternate)  
@app.route('/sirena')  
def sirena():  
    pwm.start(50)  
    # Ciclo di 2 secondi (4 iterazioni da 0.5s l'una)  
    for _ in range(4):  
        pwm.ChangeFrequency(600)  # Tono basso  
        time.sleep(0.25)  
        pwm.ChangeFrequency(1000) # Tono alto  
        time.sleep(0.25)  
    pwm.stop()  
    return "<h1>Buzzer: SIRENA ALLARME (2 secondi)</h1>"

if __name__ == '__main__':  
    try:  
        # Utilizziamo la porta 5001 per differenziarla dall'Esercitazione 3A  
        app.run(host='0.0.0.0', port=5001)  
    finally:  
        # Pulisce i pin quando il server viene interrotto  
        GPIO.cleanup()
```

Salva ed esci (`Ctrl+X`, poi `Y` e `Invio`).

## 6. Esecuzione e Test

Avvia lo script da terminale:

```bash
python3 buzzer_web.py
```

Testa le seguenti URL dal tuo browser sul dispositivo connesso al Wi-Fi del Raspberry:

* http://192.168.83.1:5001/lungo  
* http://192.168.83.1:5001/corto  
* http://192.168.83.1:5001/sirena

Sentirai il buzzer suonare con pattern diversi in base all'URL visitato. Per fermare il server, premi `Ctrl+C` nel terminale SSH.
